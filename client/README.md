# Around The U.S. - React Integration 🌎

## Description
This project is a fully responsive web application that allows users to edit their profiles, change their avatars, and manage a personalized gallery of image cards. 

In this phase of the project, the original vanilla JavaScript application was completely refactored and migrated into a modern **React** architecture using **Vite**. The user interface is now component-based, utilizing declarative rendering and React state management to create a faster, more seamless user experience.

## Features
*   **React Context API:** Global state management for user data, allowing seamless prop drilling and data sharing across nested components.
*   **Controlled & Uncontrolled Components:** Real-time form validation and DOM-node referencing (Refs) for optimized popup handling.
*   **API Integration:** Full CRUD functionality connected to a backend server. Users can fetch initial cards, update profile data, add new places, and "like" or delete existing cards.
*   **Responsive Design:** CSS Grid and Flexbox layouts ensure the application looks great on mobile, tablet, and desktop screens.

## Technologies Used
*   React (TSX)
*   TypeScript
*   Vite
*   CSS3 (BEM Methodology)
*   Asynchronous JavaScript (Promises, async/await)
*   RESTful API Integration

## Installation & Execution
To run this project locally on your machine:

1. Clone the repository to your local machine.
2. Run `npm install` to install all necessary dependencies.
3. Run `npm run dev` to start the Vite development server.
4. Open the provided localhost link in your browser.
